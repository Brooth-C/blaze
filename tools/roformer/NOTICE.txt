Blaze exports full-context FP32 weights and math. Attention batches are sliced
across independent items to bound memory; no key/query context is removed.
One checkpoint is exported into a front end, eight sequential transformer
blocks and output heads. Only one block's runtime buffers are retained at a
time. This is not a model ensemble or a shorter-context approximation.
Pipeline input: spec [1,2050,1101,2]. Output: mask [1,4,2050,1101,2].
Native source order: drums, bass, other, vocals. 44.1 kHz stereo, 11-second
contexts, original periodic Hann 2048/441 STFT, 50% overlapped chunks.
See tools/roformer/export.py for the reproducible conversion procedure.

Five-output processing subsequently uses the separately attributed Spleeter
piano model on the remaining music. This is not a native five-stem RoFormer.
