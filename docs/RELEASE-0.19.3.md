# Blaze for Mac 0.19.3

This release makes the Mac workflow easier to navigate.

- Practice retains the native sidebar and toolbar search. Opening Practice no
  longer hides navigation or changes your sidebar preference. Search works
  directly from Practice and takes you back to Explore.
- Practice has one playback area. Its controls replace the browsing mini player
  while you practise; browsing restores the mini player without restarting audio.
  Opening playback details uses the shared player, and Escape returns focus to
  the visible Practice play button.
- An empty Practice screen puts Open song and Find a song alongside the guidance
  and hides unused playback controls. Saved practices remain available.
- The WAV download menu dismisses with Escape or an outside click. Escape returns
  keyboard focus to its summary button.

These choices follow Apple's guidance on discoverable sidebar navigation,
standard toolbar controls and giving people control over hiding navigation:
https://developer.apple.com/design/human-interface-guidelines/sidebars
https://developer.apple.com/design/human-interface-guidelines/toolbars

Advanced Studio remains excluded. Separation models and GPU defaults are
unchanged. Other platform releases are unchanged.
