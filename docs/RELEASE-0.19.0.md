# Blaze for Mac 0.19.0

Blaze opens a focused Practice workspace for learning songs. Open a recording,
listen to Original, Piano or Backing, slow a difficult passage without changing
pitch, and repeat it with an A–B loop. Track switches wait for the selected
audio to load before restoring position, speed and loop settings.

Piano preparation and chord analysis run in the background. The original stays
available while piano and backing are prepared. Selecting Original during
preparation keeps that choice when the job finishes.

Save practice to retain the recording, listening mode, position, speed and loop.
Subsequent changes save automatically. Saved practices and completed separations
survive restart, and reopening a practice reuses prepared audio and its saved
chord guide. Missing or changed recordings receive an availability message.

Advanced Studio remains available as a secondary workspace. Existing download,
discovery, library, mixer, export and GPU inference capabilities are retained.
This release targets Apple Silicon and is checked on macOS 26. Other platform
downloads remain available in their existing releases.

This is a practice app, not a full DAW. One recording or stem plays at a time.
Chord recognition is a listening guide, not a piano score or note transcription.
Separation quality and runtime depend on the recording, model and hardware;
this interface update does not change model weights or establish faster inference.
