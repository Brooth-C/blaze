# Blaze for Mac 0.15.0

**Music Studio** now opens a workstation based on Apple's documented Logic Pro
layout: a compact
transport, track library, inspector, colored audio lanes and a detailed stereo
waveform editor. Import a recording or open one of the nine separated stems to
audition it in the existing player, seek, zoom, select a reference range or save
its complete WAV. Flat track headers, neutral control chrome, a compact central
display and a blue-gray audio editor follow the actual application's documented
patterns. The optional Library browses actual session tracks. The fixed stereo
amplitude gutter remains visible during waveform zoom and scrolling.
Pan, output metering, EQ, compression and project
timing controls work with the current audio audition. Chord recognition and
notation remain available from the chord button; MIDI guides use analysis notes.

Keyboard selection preserves focus, track and Inspector controls share mute/pan
state, and loading/errors remain visible in compact windows. Window/control
appearance follows the user's setting above a dark editing workspace.
The native Browse sidebar and search step aside while Studio is open, then
restore on return to Explore. Playback remains shared with Now Playing.

The workspace shows real local waveforms, with bounded previews and source
revision checks. Track lanes contain audio; this release does not add MIDI
sequencing, recording or virtual instruments. See the [workflow guide](MAC-STUDIO-WORKSPACE.md).

This build targets **Apple Silicon and macOS 26**. Other platform packages are
unchanged. Nine-stem separation and the faster five-stem/piano-only alternatives
remain available offline.
