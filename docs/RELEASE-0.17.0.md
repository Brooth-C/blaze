# Blaze for Mac 0.17.0

Studio now places real chord analysis in the main workspace: four-bar groups,
proportional chord changes within a bar, current/next context, playback following,
beat marks, and 2/4/8-bar navigation. Unknown meter is shown as time windows while
keeping detected beats visible.

The inspector and lower waveform editor support pointer and keyboard resizing;
the editor can be collapsed. Graphite surfaces, consistent focus/selection and
an integrated chord-tools palette refine the Logic-inspired working layout.
Automatic meter with an unknown denominator no longer displays `4/null`.

Playback, recognition, timing inference, saved settings and independent
background separation use the existing engines. No recording, MIDI sequencer,
multitrack mixer or instrument plug-in host is added.

Local browser coverage uses real local media and controlled musical/separation
fixtures; it does not certify model quality or physical-device audio latency.
The workflow separately checks the actual Apple Silicon package on macOS 26.
